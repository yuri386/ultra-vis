### 🔐 КАК РАБОТАЕТ АВТОРИЗАЦИЯ:

1. **Регистрация/Вход** - Данные отправляются на сервер
2. **Сервер создает JWT токен** - Валидный 30 дней
3. **Токен сохраняется** - В localStorage и in memory
4. **При загрузке страницы** - Токен восстанавливается автоматически
5. **Синхронизация между вкладками** - Если вы откроете несколько окон браузера

---

### 📊 ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ:

**Используемые технологии:**
- Backend: Node.js + Express + SQLite
- Frontend: HTML5 + CSS3 + JavaScript
- Авторизация: JWT токены
- Хранилище: SQLite БД + localStorage

**Основные файлы:**
- `frontend/js/auth-manager.js` - Главный менеджер авторизации
- `backend/routes/auth.js` - Вход и регистрация
- `backend/routes/admin.js` - Управление контентом
- `frontend/css/global.css` - Глобальные стили (шапка, модали)

**API Endpoints:**
```
POST   /api/auth/register     - Регистрация
POST   /api/auth/login        - Вход
POST   /api/auth/logout       - Выход

GET    /api/admin/stats       - Статистика
GET    /api/admin/lectures    - Все лекции
POST   /api/admin/lectures    - Добавить лекцию
PUT    /api/admin/lectures/:id - Обновить лекцию
DELETE /api/admin/lectures/:id - Удалить лекцию

GET    /api/admin/colleges    - Все колледжи
POST   /api/admin/colleges    - Добавить колледж
PUT    /api/admin/colleges/:id - Обновить колледж
DELETE /api/admin/colleges/:id - Удалить колледж
```

### 🎯 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ:

**Как зарегистрироваться на странице /lectures.html:**
```
1. Откройте http://localhost:3000/lectures.html
2. В шапке нажмите "Вход / Регистрация"
3. Перейдите на вкладку "Регистрация"

**Как добавить новую лекцию (для админа):**
```

3. Перейдите в раздел "Лекции"
4. Нажмите "+ Добавить лекцию"
5. Заполните форму
6. Нажмите "Сохранить"

```

2. Нажмите "Редактировать"
3. Измените данные
4. Нажмите "Сохранить"
5. Изменения применены и видны всем!
```

### 🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

**Проблема: Вход не работает на одной из страниц**
- Решение: Перезагрузите страницу (F5 или Ctrl+R)
- Проверьте консоль браузера (F12 → Console) на ошибки

**Проблема: Данные не сохранились**
- Решение: Проверьте, активна ли вкладка браузера
- Перезагрузите страницу

**Проблема: Админ-панель не открывается**
- Решение: Убедитесь, что вы вошли как admin
- Проверьте, что isAdmin флаг установлен в 1 в БД

**Проблема: Администратор видит обычное сообщение об ошибке**
- Решение: Проверьте F12 → Console, там детальные ошибки
